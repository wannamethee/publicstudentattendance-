# ระบบบันทึกผลการเรียนและเวลาเรียน (ปพ.5) — ฉบับเปล่าสำหรับโรงเรียน

โปรแกรมสำหรับโรงเรียนมัธยม ใช้เช็คเวลาเรียน บันทึกคะแนน และพิมพ์แบบบันทึกผลการพัฒนาคุณภาพผู้เรียน (ปพ.5)
ระบบสร้างไฟล์ ปพ.5 ทั้ง Excel และ PDF ให้อัตโนมัติจากข้อมูลที่ครูกรอก
มีตารางสอน ข้อสอบออนไลน์ แบบทดสอบย่อย ตัวช่วย AI ออกข้อสอบ เยี่ยมบ้าน การลาของครู และแดชบอร์ดสถิติในโปรแกรมเดียว

ฉบับนี้**ไม่มีข้อมูลใด ๆ** ติดมา ทั้งครู นักเรียน รายวิชา และตารางสอน
โรงเรียนกรอกชื่อโรงเรียนในหน้าตั้งค่าเริ่มต้น แล้วนำเข้าข้อมูลของตัวเองด้วยแบบฟอร์ม Excel ที่มีให้ในโปรแกรม

- **ฝั่งเซิร์ฟเวอร์:** Python (FastAPI) + ฐานข้อมูล SQLite ไฟล์เดียว
- **หน้าเว็บ:** Flutter (เปิดได้ทั้งคอมพิวเตอร์และโทรศัพท์ ไม่ต้องติดตั้งแอป)
- **ใช้งาน:** ภายในโรงเรียน (LAN) และจากที่บ้าน ถ้าเปิดลิงก์ออนไลน์ (ไม่บังคับ)

## 1. สิ่งที่ต้องมี

- **เครื่องเซิร์ฟเวอร์:** คอมพิวเตอร์ 1 เครื่องที่เปิดทิ้งไว้ระหว่างวันทำการ ใช้ Windows 10/11 หรือ Linux (Ubuntu / Xubuntu) แรม 4 GB ขึ้นไป
- **Python 3.12:** https://www.python.org/downloads/ (ตอนติดตั้งให้ติ๊ก "Add Python to PATH")
- **LibreOffice:** https://www.libreoffice.org/download/ ใช้แปลง ปพ.5 เป็น PDF (ถ้ามี Microsoft Excel ก็ใช้ได้)
- **ฟอนต์ TH SarabunPSK / TH Sarabun New:** มีให้ในโฟลเดอร์ `deploy/linux/fonts/`
- **Node.js (ไม่บังคับ):** https://nodejs.org/ ใช้เฉพาะเมื่อต้องการลิงก์ออนไลน์ผ่าน ngrok
- **ข้อมูลภาษา Tesseract (ไม่บังคับ):** ไฟล์ `tha.traineddata` และ `eng.traineddata` ไว้ใน `tools/tessdata/` ใช้อ่านข้อสอบจากไฟล์สแกน

## 2. ติดตั้ง

### Windows
1. ดาวน์โหลดโปรแกรม: กดปุ่มสีเขียว **Code → Download ZIP** แล้วแตกไฟล์ไว้ที่ `C:\schooltranscription` (หรือใช้ `git clone`)
2. เปิด Command Prompt ในโฟลเดอร์นั้น แล้วพิมพ์
   ```bat
   pip install -r requirements.txt
   ```
3. เปิดเซิร์ฟเวอร์
   ```bat
   wscript launch_background.vbs
   ```
4. เปิดเบราว์เซอร์**บนเครื่องเซิร์ฟเวอร์**ที่ `http://localhost:8000`

ให้เซิร์ฟเวอร์เปิดเองทุกครั้งที่เปิดเครื่อง: ดับเบิลคลิก `setup_autostart_on_boot.bat`

### Linux
อ่าน [deploy/linux/README_TH.md](deploy/linux/README_TH.md) (สคริปต์ `deploy/linux/setup.sh` ติดตั้งให้ครบ)

## 3. เริ่มใช้งานครั้งแรก

เปิด `http://localhost:8000` บนเครื่องเซิร์ฟเวอร์ ระบบจะขึ้นหน้า **"เริ่มต้นใช้งานระบบ"** ให้เลือก **ตั้งค่าโรงเรียนใหม่** แล้วกรอก
- **ข้อมูลโรงเรียน:** ชื่อโรงเรียน ตำบล อำเภอ จังหวัด สังกัด รหัสสถานศึกษา และชื่อผู้อำนวยการ ใช้บนหน้าปก ปพ.5 และหัวรายงาน
- **ผู้ดูแลระบบคนแรก:** ชื่อ-สกุลครู, รหัสครู และ PIN ใช้สำหรับเข้าสู่ระบบ

หน้านี้ใช้ได้เฉพาะตอนที่ระบบยังว่าง และต้องเปิดจากหน้าจอเครื่องเซิร์ฟเวอร์เท่านั้น คนอื่นจึงตั้งค่าแทนผ่านเครือข่ายไม่ได้

จากนั้นเข้าสู่ระบบด้วยรหัสครูและ PIN ที่ตั้งไว้ แล้วนำเข้าข้อมูลตามข้อ 4

## 4. นำเข้าข้อมูลของโรงเรียน

| ข้อมูล | ที่ไหน | หมายเหตุ |
|---|---|---|
| ครู ห้องเรียน นักเรียน รายวิชา ครูผู้สอน ตารางสอน | ตั้งค่า → **นำเข้าข้อมูลโรงเรียน** | ดาวน์โหลดแบบฟอร์มเปล่า กรอก แล้วอัปโหลด กด "ตรวจ" ก่อนได้ (ยังไม่บันทึก) |
| รายชื่อนักเรียนจาก DMC | เช็คเวลาเรียน → **นำเข้า DMC** | ใช้ไฟล์ที่ส่งออกจากระบบ DMC |
| รายวิชาและครูผู้สอน | ตั้งค่า → นำเข้ารายวิชาและครูผู้สอน | มีแบบฟอร์ม Excel / CSV ให้ดาวน์โหลด |
| ครูที่ปรึกษา | คลังข้อมูล → ครูประจำชั้น / ที่ปรึกษา | |
| ผลการเรียนเดิม | คลังข้อมูล → อัปโหลด SGS (PDF) หรือ ปพ.5 (Excel) | ไม่บังคับ |
| ตราโรงเรียน, ภาคเรียน, ผู้ลงนาม, สีของระบบ | ตั้งค่า | |

**PIN ของครู:** ครูที่นำเข้าใหม่ใช้รหัสครูเป็น PIN ในครั้งแรก แล้วเปลี่ยน PIN ของตัวเองได้ ผู้ดูแลระบบตั้ง PIN ให้ได้ที่หน้าตั้งค่า

## 5. ใช้งานประจำวัน

- **ครู:** เช็คเวลาเรียน บันทึกคะแนน พิมพ์ตัวชี้วัด แล้วตรวจและพิมพ์ ปพ.5 ได้จากคลังข้อมูล
- **ตัวช่วย AI (ไม่บังคับ):** ครูผู้สอนให้ Gemini ร่างแบบทดสอบย่อย / กลางภาค / ปลายภาค จากเรื่องที่ครูพิมพ์และเนื้อหาที่แนบ (ถ้าโรงเรียนมีคลังเรื่อง `lesson_topics.json` ครูติ๊กบทได้เลย) ทุกข้อมีเฉลยและวิธีทำให้ตรวจก่อนใช้ ผู้ดูแลระบบต้องใส่กุญแจ Gemini ก่อนที่ ตั้งค่า → ตัวช่วย AI ออกข้อสอบ (ขอกุญแจฟรีที่ aistudio.google.com/apikey)
- **ครูที่ปรึกษา:** เช็คชื่อโฮมรูมรายวัน ระบบนำไปคิดเวลาเรียนทุกวิชาให้เอง
- **นักเรียน:** เข้าด้วยรหัสประจำตัวนักเรียน ดูเวลาเรียนของตัวเอง ทำข้อสอบและแบบทดสอบย่อย
- **ผู้อำนวยการ:** ดูได้ทุกหน้า แต่แก้ไขไม่ได้
- **บุคคลทั่วไป:** ดูได้เฉพาะตัวเลขสรุปบนแดชบอร์ด ไม่เห็นชื่อนักเรียน

**เข้าจากเครื่องอื่น:**
- **ในโรงเรียน:** `http://<IP ของเครื่องเซิร์ฟเวอร์>:8000`
- **นอกโรงเรียน:** ใช้ลิงก์ออนไลน์ (ข้อ 6)

## 6. ลิงก์ออนไลน์ (ไม่บังคับ)

1. สมัคร https://ngrok.com (แบบฟรีได้) แล้วคัดลอก authtoken
2. สร้างไฟล์ `ngrok_token.txt` ในโฟลเดอร์โปรแกรม ใส่ authtoken ไว้บรรทัดเดียว
3. ถ้ามีโดเมนถาวรของ ngrok (บัญชีฟรีได้ 1 โดเมน) สร้างไฟล์ `ngrok_domain.txt` ใส่ชื่อโดเมน เช่น `xxxx.ngrok-free.dev`
4. ติดตั้ง Node.js แล้วพิมพ์ `npm install` หนึ่งครั้ง จากนั้นรีสตาร์ตเซิร์ฟเวอร์ (`wscript launch_background.vbs`)

ไฟล์ token และโดเมนจะไม่ถูกส่งขึ้น git และไม่อยู่ในไฟล์สำรองที่แชร์ได้

## 7. สำรองข้อมูลและอัปเดตโปรแกรม

- **สำรองอัตโนมัติ:** ระบบสำรองทั้งระบบเป็นไฟล์ .zip ทุกคืน และสำรองเองได้จากหน้าตั้งค่า ควรคัดลอกไฟล์สำรองไปเก็บนอกเครื่อง เช่น USB หรือ Google Drive
- **กู้คืน:** ทำได้ที่ ตั้งค่า → กู้คืน หรือจากหน้า "เริ่มต้นใช้งานระบบ" บนเครื่องที่ลงใหม่
- **ไฟล์สำรองอยู่ในโรงเรียน:** ไฟล์สำรองทั้งระบบดาวน์โหลด อัปโหลด หรือกู้คืนจากหน้าตั้งค่าได้เฉพาะจากเครื่องในเครือข่ายโรงเรียน ผ่านลิงก์ออนไลน์ไม่ได้ เพื่อกันข้อมูลนักเรียนรั่ว
- **อัปเดตโปรแกรม:** ดาวน์โหลดเวอร์ชันใหม่ (หรือ `git pull`) แล้ววางทับโฟลเดอร์เดิม จากนั้นรีสตาร์ตเซิร์ฟเวอร์
  - **ข้อมูลไม่หาย:** ไฟล์ข้อมูล (`school_archive.db`, `uploads/`, `outputs/`, `data/`) ไม่อยู่ในชุดดาวน์โหลด
  - **อย่าอัปเดตระหว่างสอบ:** อย่าอัปเดตขณะที่นักเรียนกำลังสอบหรือทำแบบทดสอบ

## 8. ข้อมูลส่วนบุคคล

โปรแกรมเก็บข้อมูลนักเรียนไว้ในเครื่องเซิร์ฟเวอร์ของโรงเรียนเท่านั้น ไม่ส่งออกไปที่ใด
- **ฝั่งโปรแกรม:** เลขประจำตัวประชาชนเห็นได้เฉพาะผู้ดูแลระบบ และไฟล์สำรองไม่มี PIN ของครู
- **ตัวช่วย AI:** ส่งไป Google เฉพาะเรื่องและเนื้อหาที่ครูเลือก ไม่ส่งข้อมูลนักเรียนหรือข้อสอบที่เก็บไว้ • กุญแจแบบฟรี Google อาจนำเนื้อหาไปปรับปรุงบริการ และผู้ใช้ต้องอายุ 18 ปีขึ้นไป ระบบจึงเปิดให้เฉพาะครู
- **ฝั่งโรงเรียน:** ควรกำหนดผู้ดูแลระบบและเก็บไฟล์สำรองให้เป็นไปตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA)
