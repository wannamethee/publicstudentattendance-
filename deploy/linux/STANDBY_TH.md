# ระบบสองเครื่อง: Linux (หลัก) + Windows (สำรอง)

- **Linux** ที่โรงเรียน = เครื่องหลัก เปิดตลอด
- **Windows** เครื่องแอดมิน (เอาไปใช้ที่บ้านได้) = เครื่องสำรอง เปิดเครื่องเมื่อไรจะดึงสำเนาจาก Linux ทุก 5 นาที
- ครูเข้าผ่านลิงก์เดียวเสมอ: `<ลิงก์ออนไลน์ ngrok ของโรงเรียน>` ลิงก์จะชี้ไปที่เครื่องที่ทำงานอยู่

**กฎข้อเดียว:** รับงานจากครูได้ทีละเครื่องเท่านั้น เครื่องที่ทำงานล่าสุดคือข้อมูลจริง ไม่มีการรวมข้อมูลสองฝั่ง
สคริปต์กันไว้ให้แล้วว่าสองเครื่องจะไม่เปิดพร้อมกัน แต่ **การสลับเครื่องต้องกดเองเสมอ** (ไม่สลับอัตโนมัติ เพราะเน็ตกระตุกแค่ครู่เดียวก็อาจทำให้เปิดซ้อนกันได้)

ไฟล์ที่ใช้: `standby_sync.py` (ทำงานทั้งสองเครื่อง), ปุ่มบน Windows: `standby_status.bat`, `standby_takeover.bat`, `standby_handback.bat`

---

## ตั้งค่าครั้งเดียว (วันย้ายระบบ)

1. **ติดตั้ง Tailscale ทั้งสองเครื่อง** และล็อกอินบัญชีเดียวกัน เพื่อให้สองเครื่องคุยกันได้แม้อยู่คนละที่ (ไม่ต้องเปิดพอร์ตที่เราเตอร์)
   - Windows: ดาวน์โหลดจาก tailscale.com แล้วล็อกอิน
   - Linux: `sudo bash deploy/linux/setup.sh` ติดตั้งให้แล้ว จากนั้นรัน `sudo tailscale up` แล้วเปิดลิงก์ที่แสดงเพื่อล็อกอิน
   - ดูชื่อเครื่อง Linux ใน Tailscale (เช่น `school-server`) ด้วย `tailscale status`
2. **บน Linux**: รัน `sudo bash deploy/linux/setup.sh` (รันซ้ำได้ปลอดภัย) ซึ่งจะ
   - ให้บริการ `school-api` / `school-tunnel` ตรวจก่อนเริ่มทุกครั้งว่า Windows ทำงานแทนอยู่หรือไม่
   - ติดตั้ง ssh และให้สคริปต์หยุด/เริ่มได้แค่ 2 บริการนี้ (ไม่ต้องใช้รหัสผ่าน)
3. **บน Windows** (หลังจาก Linux ทำงานจริงและครูใช้ลิงก์ได้แล้ว): ดับเบิลคลิก `setup_standby_windows.bat`
   - แก้ `standby_config.json` ที่เปิดขึ้นมา: `primary_ssh` = `ชื่อผู้ใช้@ชื่อเครื่องใน Tailscale`, `primary_dir` = โฟลเดอร์ระบบบน Linux
   - สคริปต์จะ **ยกเลิกการเปิดเซิร์ฟเวอร์เองตอนเปิดเครื่อง** (ไม่งั้น Windows จะแย่งลิงก์กับ Linux), ส่งกุญแจ ssh ให้ Linux (ถามรหัสผ่าน Linux 1 ครั้ง), ตั้งเวลาซิงค์ทุก 5 นาที และซิงค์ครั้งแรก
4. ดับเบิลคลิก `standby_status.bat` ต้องเห็น `ลิงก์ออนไลน์ -> Linux (เครื่องหลัก)` และ `Linux: ติดต่อได้, ทำงานปกติ`

## เมื่อ Linux ล่ม (ไฟดับที่โรงเรียน / แบตหมด / เน็ตโรงเรียนดับ / เครื่องเสีย)

1. เปิด Windows ที่ไหนก็ได้ที่มีเน็ต ดับเบิลคลิก **`standby_takeover.bat`** แล้วพิมพ์ `y`
2. สคริปต์จะ
   - ไม่ยอมสลับ ถ้าลิงก์ยังมี Linux ตอบอยู่ (แปลว่าครูยังใช้งานได้ ไม่ต้องสลับ)
   - ถ้ายังติดต่อ Linux ได้: สั่ง Linux หยุดและดึงข้อมูลล่าสุดมาก่อน (ไม่มีข้อมูลหาย)
   - ถ้าติดต่อไม่ได้: ใช้สำเนาจากการซิงค์ครั้งล่าสุด (แสดงว่ากี่นาทีก่อน)
   - เปิดเซิร์ฟเวอร์และลิงก์บน Windows — ครูใช้ลิงก์เดิมต่อได้เลย
3. ระหว่างทำงานแทน ห้ามปิดเครื่อง/ปิดฝาจอ ถ้าเผลอรีสตาร์ต รอบอัตโนมัติจะเปิดเซิร์ฟเวอร์ให้ใหม่ภายใน 5 นาทีหลังล็อกอิน

**ข้อจำกัดที่ต้องรู้**
- ถ้าไฟดับกะทันหัน งานที่ครูบันทึกหลังรอบซิงค์ล่าสุด (ไม่เกิน 5 นาที) จะยังอยู่ในเครื่อง Linux เท่านั้น
  เมื่อ Linux ติดต่อได้อีกครั้ง `standby_status.bat` จะแจ้ง `!! มีข้อมูลบน Linux ช่วงก่อนล่ม...` พร้อมที่เก็บสำเนา (`backups/standby/held_*.db` บนเครื่อง Linux) ให้ครูบันทึกรายการช่วงนั้นซ้ำ
- ถ้า Windows ปิดเครื่องไว้หลายวัน สำเนาจะเก่าตามนั้น — เปิด Windows ทิ้งไว้บ้างเพื่อให้ซิงค์

## เมื่อ Linux กลับมา

- ไฟกลับมาแล้ว Linux บูตเอง **จะไม่เปิดรับงานเอง** ถ้า Windows ทำงานแทนอยู่ (เช็คจากลิงก์ออนไลน์ และพอ Windows ติดต่อได้จะสั่งพัก Linux ภายใน 5 นาที)
- เลือกเวลาที่ครูไม่ค่อยใช้งาน ดับเบิลคลิก **`standby_handback.bat`** แล้วพิมพ์ `y`
  - หยุด Windows → ส่งฐานข้อมูลและไฟล์ที่เปลี่ยนทั้งหมดให้ Linux → Linux เปิดบริการ → ลิงก์กลับไปที่ Linux
  - ใช้เวลาประมาณ 1–5 นาที ระหว่างนั้นครูเข้าไม่ได้ชั่วคราว
  - Linux เก็บฐานข้อมูลและไฟล์เดิมที่ถูกแทนไว้ที่ `backups/standby/before_handback_*` เผื่อต้องย้อนดู
  - ถ้าส่งไม่สำเร็จ Windows จะเปิดเซิร์ฟเวอร์กลับมาทำงานแทนต่อเอง ไม่มีช่วงที่ไม่มีใครทำงาน

## แก้ปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| `Linux: ติดต่อไม่ได้` ทั้งที่ Linux เปิดอยู่ | ตรวจว่า Tailscale เปิดและล็อกอินทั้งสองเครื่อง (`tailscale status`) |
| ซิงค์แจ้ง `ทับไม่ได้ N ไฟล์` | มีไฟล์ ปพ.5 เปิดค้างใน Excel บน Windows — ปิดแล้วรอรอบถัดไป |
| Linux ไม่ยอมเปิดบริการ ทั้งที่ Windows ไม่ได้ทำงานแทนแล้ว | บน Windows สั่ง `python standby_sync.py handback --force` (ส่งข้อมูลจาก Windows ไปทับ) หรือถ้าข้อมูลบน Linux ถูกต้องอยู่แล้ว: บน Linux ลบไฟล์ `HELD_BY_STANDBY` แล้ว `sudo systemctl start school-api school-tunnel` |
| ดูประวัติการทำงาน | `standby_sync.log` (ทั้งสองเครื่อง) |
